# GEMINI.md

This repository's agent rules live in two files; read them instead of this
one:

1. [`AGENTS.md`](AGENTS.md) — environment, safety, build and CI workflow.
2. [`rules.md`](rules.md) — hard rules (device safety, language, patch
   discipline, git, debugging, handoff).

Then read [`progres.md`](progres.md) for the live state and
[`docs/STATUS.md`](docs/STATUS.md) for the latest boot result.

Do not duplicate rules here. If a rule must change, edit `rules.md` (or
`AGENTS.md`) and leave this file as the pointer.
